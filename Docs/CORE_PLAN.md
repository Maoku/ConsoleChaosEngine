# ゲーム主題

コンソールゲーム機における4つの世代
- ファミコン
- スーパーファミコン
- PlayStation 1
- PlayStation 2
それぞれの世代が技術的制約を持ったままが１つのゲーム内で混在する
プレイヤーはシームレスに4つの世代の渡り歩くことでクリアを目指す
謎解きアクションゲーム
遊びながら、ゲームの世代の技術的な差異を体感させたいというもの

ブラウザゲームとして実装する

## 4つの世代の混在とは？

１つのゲームの中で、擬似的に各世代のコンソールゲーム機の制約をかける。制約は以下の項目である

- グラフィックス
- サウンド
- 入力（コントローラー）

ゲームにおけるユーザーとのインタラクション部分…入力と出力部分が各コンソール世代に変換されるイメージで、CPU性能やメモリについては制約を行わず、１つのゲームシステムで動かす

### 世代の違いを遊びの要素に加える

シームレスに世代を行き来することで、各コンソール世代の技術的差異を理解できるしたい

一例では
- 色数差: ファミコン世代の色数だけど気づけないが、スーパーファミコン世代ならわかる謎
- 次元差: 2Dだと敵の弱点が見えないが、3Dにすると弱点攻撃可能に

など、技術的差異から体感のさせ方を考える

### 表示としての統一

各世代で内部的なグラフィックス解像度が異なるが
表示装置としてブラウン管テレビに表示されているという設定とし
見た目としてのサイズは揃える

# ポイント

新しい世代が最高の体験というわけではなく、それぞれの世代の魅力を伝える

例えば、ファミコンであれば少ない色数やパターンでわかりやすく伝える表現をしているなど
