# ConsoleChaosEngineの拡張

実装計画段階で、 エンジンレイヤーに実装するものを明示化する
- ラスタースクロール
- アフィン変換
- 環境マップ


# グラフィックス

それぞれの世代のレーシングゲームの表現を用いる

## 第1世代

ラスタースクロールを用いて、車体の背後視点で奥に進むような見え方にする

## 第2世代

背景のアフィン変換技術を用いて、擬似3Dのコースを走行

## 第３世代

3Dのレースゲーム

## 第4世代

3Dのレースゲーム
環境マップやライティング
