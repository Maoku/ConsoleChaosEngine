# 目的

Opus5ConsoleChaos のソースコードはシステムやギミックがレイヤー分けされていない状態。これを

- 4つのコンソール世代の表現を切り替えできるゲームエンジン
- そのゲームエンジンで実装した謎解きアクションゲーム

になるようにレイヤー分けのリファクタを行なってほしい。
ゲームエンジン化の目的は、謎解きアクションゲームに限定されないシステムの再利用にある

# ゴール

1. Opus5ConsoleChaos の謎解きアクションゲームが、ゲームエンジン化しても忠実かつ完全に再現されること
