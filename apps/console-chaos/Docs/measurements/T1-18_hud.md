## 1. 受け入れ条件（IMPLEMENTATION_PLAN §8.2）

| 条件 | 判定 | 根拠 |
|---|---|---|
| CRT フレームの外側に表示される | **満たす** | §2 の実測（帯とキャンバスの矩形が重ならない） |
| ゲーム画面の再現性を汚さない | **満たす** | HUD は DOM のみ。描画パイプラインへ触れないことをテストで検査 |

## 2. 「外側」をレイアウトで保証する

ページを 3 行のグリッドにした（`index.html`）。

```
#app  ┌──────────────── #hud-top（40px）
      │  #stage（1fr）… ゲーム画面。ここだけがキャンバス
      └──────────────── #hud-bottom（40px）
```

キャンバスの表示サイズは `#stage` に収まるよう実測で決める（`fitCanvasToStage`）。
内部解像度（世代プロファイルが決める）は触らない。

**ブラウザ実測（1280×720）**

| 要素 | 位置 |
|---|---|
| 上の帯 | y 0 〜 40 |
| ゲーム画面 | x 213.5、y 40 〜 680（853×640。960×720 を 8/9 に縮小） |
| 下の帯 | y 680 〜 720 |

帯とキャンバスの矩形は重ならない（`hud-top.bottom <= canvas.top && hud-bottom.top >= canvas.bottom`）。

CSS の `max-height:100%` では fr トラックの中で百分率が解けず、
キャンバスが 720px のまま帯を画面外へ押し出した。実測で決める方式に変えて解消した。

## 3. 表示する 4 つ

| 表示 | 位置 | 内容 |
|---|---|---|
| チャンネル | 上帯・左 | `CH 3 / 第3世代`。切替中・予約中は `→ CH 4` を併記 |
| 進行 | 上帯・右 | `0 / 6`（解けたパズル数 / 配置数）。順路は示さない |
| ヒント | 下帯 | `ヒント n／4 <本文>` + ペナルティ無しの注記（T1-17） |
| 復帰の暗転 | 画面に重ねる | `checkpoint.fadeAmount` をそのまま不透明度に |

**暗転だけがキャンバスに重なる。** 情報表示ではなく画面遷移そのもので、
暗転中はどのみち世代の見えを確認できないため（判断の記録）。

## 4. 強制切替の予告（GAME_PLAN §5.4 / T3-02 への地ならし）

`switcher.warningTo` を足して、予告中の行き先を UI が先出しできるようにした。
点滅周期は 0.5 秒（`WARNING_BLINK_PERIOD_MS`）。速い明滅は光過敏の配慮に反するため、
意図的にゆっくりにしてある。帯そのもの（`ui/forced_banner.ts`）は T3-02。

## 5. 試遊用オーバレイとの関係

`debug/playtest_hud.ts`（G0-1 の試遊キット）が持っていたチャンネル表示は削除した。
本番の HUD と二重に出るため。試遊オーバレイに残したのは操作の案内とクリア時間だけ。
