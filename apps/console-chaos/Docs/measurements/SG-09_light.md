## 1. 環境光が色を持った

`uniform float uAmbient` を `uniform vec3 uAmbient` にした。**uniform は増えていない。**

```glsl
// 拡散光と松明は白いまま（光源の色は 1 つに保つ）。色を持つのは環境光だけ
vec3 shade = min(uAmbient + vec3(uDiffuse * lambert + torch), vec3(1.0));
```

基準画の J（太陽が高い。天面が明るく飛び、**影は青みに沈む**）はこれで出る。
改訂前の環境光は無彩色の係数 1 つだったので、影がただ暗いだけだった。

## 2. 明度で正規化するのが要点

渡すのは `material.ambient × tint`、`tint = 空の下端色 ÷ その明度`。

**正規化しているので `luma(tint) = 1` である。** つまり `ambient` が持つ
「陰影の取り分」の意味はまったく変わらない。変わるのは影側の**色相だけ**になる。

| | 改訂前 | SG-09 |
|---|---|---|
| 陰影の式 | `ambient + diffuse × lambert` | `ambient × tint + diffuse × lambert` |
| 陰影の明度 | `ambient` | `ambient`（`luma(tint) = 1` なので同じ） |
| 陰影の色 | 無彩色 | 空の下端の色相 |

## 3. 空の見えない部屋では色だけが戻る ⚠

判断 G は「背景と同じ係数（`frame.backdrop.brightness`）を掛ける」と書いていたが、
素直に掛けると**環境光そのものが 0 になる**。暗室（P2-1）は
「松明の外は真っ黒」から「完全な暗闇」へ変わってしまい、
同じ SG-09 の受け入れ条件「暗室の明度が変わらない」と食い違う。

そこで掛け算ではなく**無彩色との混ぜ**にした。

```ts
ambientTint[c] = 1 + ((horizon[c] / skyLuma) - 1) * frame.backdrop.brightness;
```

- `brightness = 1`（屋外）… 空の色そのもの
- `brightness = 0`（暗室）… `[1,1,1]`（無彩色）

**混ぜている 2 つはどちらも明度 1** なので、どの途中の値でも取り分は材質の値のままである。
「空の見えない部屋では環境光の色も一緒に落ちる」（判断 G の意図）は満たしつつ、
受け入れ条件のほうも壊さない。

落ち影の板とスプライトには `[1,1,1]` を渡す（絵に陰影が焼き込まれているので色を乗せない）。

## 4. 実測：暗室の明るさは 1 の位まで変わっていない

`?scene=mini&level=area1&playtest=0` を `window.__chaos` で 1 フレーム描き、
`readPixels` の平均明度を取った（CRT off、240 ティック進めてから）。

| 場所 | SG-09 前 | SG-09 後 |
|---|---|---|
| 暗室（`p2_1`、第4世代） | **21.83** | **21.83** |
| 暗室（`p2_1`、第3世代） | **4.82** | **4.82** |
| 屋外（`start`、第4世代） | 127.80 | 127.59 |

**暗室は完全に一致する**（`brightness` が 0 なので `tint = [1,1,1]`、
つまり改訂前とビット単位で同じ式になる）。

屋外の 0.21 の差は色相が動いたぶんの丸め誤差である。
影側が青みに沈み、天面との差が色でも読めるようになった。

## 5. 「第4世代だけの署名」を影へ移した

SG-03 で廃止した「第4世代の背景は第3世代より暗い」の置き換えとして、
`backdrop.test.ts` に**落ち影の署名**を足した。

```
落ち影を落とすのは第4世代だけ（video.dynamicLight が真な世代とちょうど一致）
```

**世代 ID は書かない。** 見るのは `dynamicLight` を持つ世代の一覧で、
`chaos/no-generation-branch` の趣旨をテストの側でも守る。
4 世代とも昼になった以上、第4世代の署名は暗さではなく影が担う。

環境光の側にも 1 件足した（正規化の式そのものと、
どの世代の空の下端も明度 0 でないこと＝0 で割らないこと）。
