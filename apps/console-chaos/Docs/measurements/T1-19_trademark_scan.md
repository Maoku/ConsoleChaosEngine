## 2. 自動検査の穴を 1 つ塞いだ

`.gltf` と `.py` を**中身の検査対象に加えた**。

glTF は JSON で、Blender のオブジェクト名・マテリアル名・アニメ名がそのまま入る。
アセット側の混入経路としては一番危ないのに、拡張子が対象外だったため
`public/assets/models/player.gltf` の中身は検査されていなかった
（ファイル名だけは検査されていた）。`tools/blender_export_player.py` も同じ理由で加えた。

追加後も検出ゼロ。走査したファイル数を出力に出すようにして、
「全走査した」ことが CI のログで確認できるようにした。

内容を検査しないのは `public/assets/models/player.bin`（バイナリ）1 件のみ。
ファイル名は検査対象に含まれている。

## 4. 続けて守るための決まり

- 表示名は `generation/profiles.ts` の `DISPLAY_NAMES` だけを使う。UI に文字列を直書きしない
- アセットを追加したら `npm run check:assets` と `npm run check:trademark` の両方を通す
- モデルを作り直したときは、**Blender のオブジェクト名**を先に確認する（glTF に残るため）
- ロゴ・固有形状は自動検査できない。アセット追加時のレビュー項目として残す
  （`check:trademark` の出力にもその旨を出すようにした）
