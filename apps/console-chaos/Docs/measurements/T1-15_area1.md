## 2. 受け入れ条件

| 条件 | 判定 | 根拠 |
|---|---|---|
| チェックポイント復帰が 1 秒以内 | **満たす** | 24 ティック = 0.4 秒（`RESPAWN_TOTAL_TICKS`）。テストで固定し、実ブラウザでも落下 → 出発点復帰を確認 |
| 15 分でプレイできる | **未判定**（下記） | 通しは成立するが、所要時間は人にしか測れない |

### 「15 分」について

最短経路を機械的になぞる通し走行は **1,826 ティック = 30.4 秒**で終わる。
これは「レベルが端から端まで繋がっており、6 件すべてが解ける」ことの証明であって、
プレイ時間の実測ではない。実際の 15 分は**どの世代を試すかを探す時間**が占める。

したがって「15 分でプレイできる」の判定は **T1-20 の外部プレイテスト**で行う。
1 人あたりの所要時間を記録し、15 分から大きく外れる場合は部屋数か
1 部屋あたりの探索量で調整する。

## 3. 通し走行の記録（回帰テスト）

`area1_full_run.replay.json` は、下記の入力列で 6 件すべてを解いて
ゴール前（x = 117.108）に立って終わる。同じ入力からは必ず同じ結果になる（不変条件 I4）。

| 区間 | 世代 | 解けるもの |
|---|---|---|
| 出発 → 2D の橋 → F-1 の橋 → 台座 | 第1 | F-1 |
| P1-1 の壁を奥から回る | 第3 | P1-1 |
| S-1 の半透明の足場を渡る | 第3 | S-1 |
| F-2 の落とし穴へ落ちる | 第1 | F-2 |
| P1-2 の殻をすり抜ける | 第3 | P1-2 |
| P2-1 の刻印を踏む | 第4 | P2-1 |

**実ブラウザで同じ入力を流すと、最終位置が小数第 2 位まで一致する**
（リプレイ 117.108 / ブラウザ 117.11）。画面とテストが同じ組み立て
（`gameplay/session.ts`）を通っていることの確認になっている。

## 4. 制作中に直したもの

| 問題 | 対応 |
|---|---|
| 下の層から元の高さへ戻る階段が、幅 0.5m・1m 刻みで登れない | 階段をやめ、**F-2 から先を 4m 下の層に統一**した。登り返しを要求しない |
| F-2 の台座が落下地点から離れていて触れない | 穴が開く位置（右端）の真下へ移した |
| P1-2 の核が細く、殻を抜けても触れない | 奥行きに幅を持たせ、通れば必ず触れるようにした |
| カメラがプレイヤーを 0.6 倍でしか追わず、長いレベルで置いていかれる | **1:1 追従**に変更 |
| 2D の表示倍率が中途半端で、第1世代のブロック境界とズレる | `orthoHeight = internalHeight / 32` に固定（T1-08 の計測どおり、1 単位 = 32 画素） |
