# T0-19 プレイヤーモデルの FC 量子化表示 — 初期確認と所見（§16.1-d への入力）

| 項目 | 値 |

## 1. 目的

本作のプレイヤーは**全世代で 3D モデル**であり、第1世代ではそれを量子化して表示する
（GAME_PLAN §16-2：ドット絵への差し戻しはしない）。
したがって「量子化後もシルエットと部位が読めるか」がモデル設計の制約になる。
造形の良し悪しではなく、**低頭身・高コントラストという方針が量子化に耐えるか**を見る。

## 3. 所見

### 読めるもの

- **全身のシルエット**は明確に読める。頭・胴・脚・足の 4 つの塊が分離している
- **大きな面積を持つ色は残る。** 赤い胴、青い脚、黄色い足は量子化後も原色のまま残り、
  「どこが何か」が一目で分かる
- 第4世代（`PS2.png`）と並べても、**同じキャラクターだと分かる**。
  世代が変わってもプレイヤーの同一性は保たれている

### 失われるもの（重要）

- **細い特徴は消える。** 髪（厚み 0.24 相当）はブロック内で少数派になり、
  左上の一部を除いて背景・顔と同じ代表色に吸収された
- **手（肌色の小さな箱）が腕と胴に混ざる。** 16×16 ブロックの中で
  「赤い胴 + 肌色の手 + 背景」の 3 色に収まりきらず、灰色寄りの中間色へ潰れている
- **ブロック境界がキャラクターを横切る**と、そこで色が切り替わって見える。
  静止時は気にならないが、移動中はブロック境界がキャラに対して動くため、
  色が明滅する可能性がある（要確認：T1-08）

### 背景の影響

暗い背景（`dark_bg.png`）では、ブロック内の色数に余裕ができるため
キャラクターの色がより多く残る。**背景の明度設計がキャラの読みやすさに直結する。**

## 4. モデル設計への申し送り（T1-08 の入力）

1. **特徴は 16 画素以上の塊で作る。** 髪・目・装飾など 8 画素以下の要素は
   量子化で消えると考えて設計する
2. **隣接部位は色相ではなく明度で分ける。** 量子化の代表色選択は面積で決まるため、
   小さい部位は「色相が違う」だけでは残らない
3. **手足の先端に明るい色**を置く方針は有効だった（黄色い足は完全に残った）。
   ただし面積を稼ぐこと
4. キャラクターが立つ場所の背景は、**明度を落とすか単色に寄せる**。
   レベル制作側の制約として asset-rules に追記する候補
5. ブロック境界とキャラの相対位置が動くことによる色の明滅は、
   T1-08 でアニメーション付きの状態で再確認する

## 4.5 実アセット（Blender 出力）での再確認

上記の所見を反映したモデルを Blender 5.1.2 で作り直し
（`tools/blender_export_player.py`、3 ボーン / 108 三角形 / 待機アニメ付き）、
ゲームと同じ経路で 4 世代表示した。

| ファイル | 内容 |
|---|---|
| `t0-06_blender_player_FC.png` | 第1世代（カラークラッシュ + CRT(RF)） |
| `t0-06_blender_player_PS1.png` | 第3世代 |
| `t0-06_blender_player_PS2.png` | 第4世代 |

- 髪を厚く（0.16）したことで、第1世代でも**黒い塊として残るようになった**。
  「特徴は塊で作る」という申し送りが実際に効くことを確認
- 一方で顔と髪の境界はブロック境界に依存して割れる。
  頭部の高さをブロック境界に合わせる調整は T1-08 で行う

### 世代ごとのアニメーション量子化（asset-rules.md §6 の規則の実地確認）

アセットは滑らかなアニメを 1 本だけ持ち、**再生時刻の量子化**で世代差を出す。
CRT のノイズを止めて画面差分の画素数を測った結果：

| 条件 | 変化した画素数 |
|---|---:|
| 第1世代、同じ 1/6 秒コマ内（t = 0.00 と 0.10） | **0** |
| 第1世代、コマをまたぐ（t = 0.00 と 0.20） | 1,667 |
| 第4世代、t = 0.00 と 0.10（60fps） | 135 |

第1世代では 6fps のコマ落ちが**完全に**成立しており、
第4世代では滑らかに動いている。アセット側にコマ落ちを作る必要はない。

## 5. 結論（暫定）

**低頭身・高コントラストの方針は量子化に耐える。** ただし
「細部を描かない」ことが前提であり、モデルは**部位ごとの塊で構成する**必要がある。
この所見を GAME_PLAN §16.1-d の判断材料とする。最終判断はフェーズ 1 のゲート G1-2
（FC 表示のキャラが読める・魅力があるか）で行う。
