## 3. 【新しい発見】グリッド整列はカメラの縮尺と揃って初めて効く

モデルを 0.25 単位（8 画素相当）に整列させても、**カメラが 1 ワールド単位を
32 画素に写していなければ意味がない。**

| 条件 | 1 単位あたりの画素 | 頭部の見え |
|---|---:|---|
| 寄り（`orthoHeight` 2.6） | 86 px | ブロック境界が顔を横切り、左右で色が割れる |
| 実寸（`orthoHeight` 7 = 224 / 32） | 32 px | 部位の境界とブロック境界が一致し、割れない |

横位置を 1/8 単位（4 画素相当）ずつずらして、キャラに出ている色の面積を数えた：

| ずらし量 | 実寸（32px/単位）の面積 | 寄り（86px/単位）の面積 |
|---|---|---|
| 0 | 赤 5400 / 黒 2896 / 橙 2340 / 黄 1976 / 青 1560 | 赤 40056 / 黒 19576 / 橙 16752 |
| 0.125 | 同上（完全一致） | 赤 39386 / 黒 20308 / 橙 17324 |
| 0.25 | 同上（完全一致） | 赤 39794 / 黒 21193 / 橙 16958 |
| 0.375 | 黄のみ 1950（-1.3%）、他は一致 | 赤 39896 / 黒 20396 / 橙 16752 |

**実寸では色の集合も面積もほぼ完全に一致する** = 移動中の明滅は起きない。
寄りでは面積が 1〜8% 揺れる（縁の処理によるもので、色の集合自体は変わらない）。

> **T1-15 への申し送り**：2D 投影の世代のカメラは
> `orthoHeight = internalHeight / PIXELS_PER_WORLD_UNIT`（第1・第2世代なら 224 / 32 = 7）
> に固定すること。レベルの 0.25 単位グリッド（T1-07）とカラークラッシュのブロック、
> モデルの部位境界がすべて一致する。

## 4. 【新しい発見】第1世代のパレットには「中明度の低彩度な暖色」が無い

肌色 (0.98, 0.86, 0.72) はライティングで暗くなった瞬間に**灰色 (152,150,152)** へ落ちる。
顔が灰色の塊になり、頭部が読めなくなっていた。

| 色 | 明るさ 1.0 | 0.85 | 0.7 | 0.55 | 0.4 |
|---|---|---|---|---|---|
| 旧・肌 (0.98,0.86,0.72) | 白 | 肌 | **灰** | **灰** | **灰** |
| 新・顔 (0.92,0.62,0.35) | 橙 | 橙 | 橙 | 茶 | 茶 |
| 旧・髪 (0.10,0.11,0.24) | 暗青緑 | **暗オリーブ** | 黒 | 黒 | 黒 |
| 新・髪 (0.06,0.06,0.10) | 黒 | 黒 | 黒 | 黒 | 黒 |

**アセットの色は、量子化後の系統が明度によって変わらないものを選ぶ。**
淡い色（低彩度・高明度）は第1世代で必ず灰色に落ちる。
この規則は `Docs/asset-rules.md` の色の指針として今後のアセットにも適用する。

## 5. 世代ごとのアニメーション量子化（歩行アニメで再確認）

CRT のノイズを止め、画面差分の画素数を数えた（960×720 出力、実寸表示）。

| 条件 | 変化した画素数 |
|---|---:|
| 第1世代、同じ 1/6 秒コマ内（t = 0.00 と 0.10） | **0** |
| 第1世代、コマをまたぐ（t = 0.00 と 0.20） | 5,582 |
| 第4世代、t = 0.00 と 0.10（60fps） | 53,071 |

歩行アニメでも第1世代の 6fps コマ落ちは**完全に**成立している。
アセットは滑らかな 1 本を持ち、コマ落ちは再生時刻の量子化だけで作る
（`asset-rules.md` §6 の規則が守られていることの再確認）。
